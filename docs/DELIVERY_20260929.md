## 사용할 파일

회사: ZIP 압축 해제 → SETUP.cmd → .env 연결 정보 입력 → CHECK.cmd → START.cmd.
합성 데이터/Python API: DEMO.cmd. 회사 서비스나 운영 DB를 사용하지 않습니다.
서버 없는 화면: site/index.html 또는 Release의 SCM_Demo.html.
최신 ZIP: https://github.com/dalmook/Realtime/releases/latest/download/SCMRealtimeDB_portable.zip

## 검증 범위 밖

회사 Splunk 및 Oracle 실제 연결, SAP 숫자 대조, 사용자 PC의 Instant Client/드라이버 조합은 외부 환경에서 확인하지 않았습니다. Oracle Thick 드라이버와 Instant Client는 회사 승인 설치본이 필요합니다. BOX는 CARTON의 실제 의미가 확인된 후 활성화해야 합니다. 재고에는 목표나 임의 추정 수량을 넣지 않았습니다.

실제 .env, 업무 DB·조회 결과·로그, DLL·패키지 바이너리는 배포 파일에서 제외합니다. GitHub Pages에는 합성 데이터만 배포하도록 구성했습니다. 웹 배포 성공 여부는 Pages 작업 결과를 확인하세요.
