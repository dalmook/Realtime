SCMRealtimeDB Portable 1.2.4-realtime
===================================

가장 먼저 읽기:
  docs\LOCAL_RUN_WORK_INSTRUCTION_KO.md

화면만 확인:
  site\index.html       - Python 불필요, 완전 합성 데이터
  DEMO.cmd              - 별도 합성 SQLite + 실제 Python API

회사 로컬 실행:
  1. 새 폴더에 ZIP 압축 해제
  2. SETUP.cmd
  3. .env에 승인된 Splunk / Oracle 정보 입력
  4. CHECK.cmd
  5. SYNC_ORACLE.cmd        [이번 환산 변경판 최초 1회 필수]
  6. VERIFY_CONVERSION.cmd  [실제 MATNR 하나로 환산 확인]
  7. START.cmd

환산 기준:
  Splunk MATNR = Oracle ITEM
  CONV_CODE로 DRAM/FLASH 구성 분리
  환산수량 = QTY * CONVEQQTY
  K4*/PD* = DRAM, K9* = FLASH
  환산 구성은 여러 행이어도 EA/QTY, BOX, USD 원본값은 중복 집계하지 않음

기존 DB:
  기본 위치 %LOCALAPPDATA%\SCMRealtimeDB\live\scm_live.sqlite
  예전 P_CODE 기반 DB는 원문 MATNR가 모두 있을 때만 안전하게 1회 이관
  MATNR 누락 오류가 나면 DB 삭제/reset-source로 우회하지 말 것
  예전 EQQTY 환산값은 무효화되므로 SYNC_ORACLE.cmd 성공이 필요

Python 3.11+ / Oracle Thick + 승인된 Instant Client 필요.
자동 PyPI 다운로드나 회사 보안 설정 변경은 하지 않습니다.
